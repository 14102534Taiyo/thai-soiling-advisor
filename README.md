# ระบบแนะนำวันล้างแผงโซลาร์เซลล์ (Thai PV Soiling Cleaning Advisor)

เครื่องมือช่วยตัดสินใจว่า**ควรล้างแผงโซลาร์วันไหนถึงจะคุ้มค่าทางเศรษฐศาสตร์ที่สุด**
โดยใช้แบบจำลองฟิสิกส์สำเร็จรูป (ไม่เทรน ML เอง) ขับเคลื่อนด้วยข้อมูลฝุ่น/ฝน/แสงจริง
ของแต่ละพื้นที่ในไทย ผ่านแดชบอร์ด Streamlit ที่อัปเดตทุกวัน

## วิธีติดตั้งและรัน

```bash
pip install -r requirements.txt
streamlit run app.py
```

ไม่ต้องมี API key ใดๆ สำหรับการรันพื้นฐาน (Open-Meteo, Air4Thai, TMD ทั้งหมดใช้ credential
สาธารณะที่ฝังไว้ในโค้ดแล้ว) เปิดเบราว์เซอร์ไปที่ `http://localhost:8501`

## แนวทางที่ใช้ (Approach)

1. **อากาศ + ฝุ่นดิบ** — Open-Meteo: ข้อมูลย้อนหลัง + พยากรณ์ล่วงหน้าสำหรับ GHI/DNI/DHI,
   ฝน, อุณหภูมิ, ลม, PM2.5/PM10
2. **ฝุ่นจริง (ปรับเทียบ)** — Air4Thai (เรียลไทม์) + PCD Open Data (ย้อนหลัง) แก้ bias ของ
   CAMS Global ด้วยตัวคูณรายเดือน
3. **ฝนจริง (ยืนยัน/แก้ไข)** — สถานี TMD ตรวจสอบฝนพยากรณ์ทุกเช้า ยกเลิกการรีเซตที่พยากรณ์
   ผิดโดยอัตโนมัติ พร้อม log ถาวรกันข้อมูลย้อนกลับผิด
4. **แบบจำลองความสกปรก** — `pvlib.soiling.hsu` (ขับเคลื่อนจากฝุ่น+ฝนจริง ไม่ใช่อัตราคงที่
   ที่ตั้งเอง) เช็คฝนเป็นรายชั่วโมงตามงานวิจัย (Norde Santos et al. 2024)
5. **พลังงานที่ควรผลิตได้** — pvlib PVWatts chain (POA transposition + อุณหภูมิแผง +
   inverter) ปรับได้ตามสเปกระบบจริง (kWp, DC/AC ratio, มุมเอียง, ค่าสัมประสิทธิ์อุณหภูมิ,
   ประสิทธิภาพระบบ)
6. **เศรษฐศาสตร์** — หาจำนวนวัน T ที่ทำให้
   `ACR(T) = ต้นทุนค่าล้างเฉลี่ย/วัน + มูลค่าไฟที่เสียเฉลี่ย/วัน` ต่ำที่สุด คำนวณใหม่ทุกวัน
7. **แดชบอร์ด** — Streamlit, 3 แท็บ (ภาพรวม / รายละเอียดเศรษฐศาสตร์ / เกี่ยวกับโมเดล)

## การปรับเทียบ/ตรวจสอบที่ทำแล้ว

- **Deposition velocity**: ปรับเทียบกับงานวิจัยภูมิภาค (คาลิเบรทด้วยช่วงหน้าแล้งเพื่อเลี่ยง
  seasonal bias) ได้ ~0.17%/วัน หน้าแล้ง, ~0.12%/วัน หน้าฝน
- **มุมเอียงแผง**: ทดสอบข้อมูลจริงเต็มปี 2025 พบมุมที่ดีที่สุด = 15° ตรงกับมาตรฐานอุตสาหกรรม
  ไทย (10-15°)
- **เกณฑ์ฝนล้างแผง**: รายชั่วโมง (ไม่ใช่รายวัน) ตาม Norde Santos et al. 2024 (Solar RRL)
- **Cross-validation**: เทียบ Open-Meteo กับ NASA POWER (ดาวเทียม) ได้ MAE ~16% ไม่มี bias
  เชิงระบบ

## ข้อจำกัดที่ควรรู้

- การล้างแผงจากฝนเป็นแบบ all-or-nothing (ทั้งหมดหรือไม่เลย) — ข้อจำกัดที่มาจากตัวฟังก์ชัน
  `pvlib.soiling.hsu` เอง ไม่ใช่แค่พารามิเตอร์ที่ปรับได้
- `deposition_velocity` ยังปรับเทียบกับค่าเฉลี่ยภูมิภาค ไม่ใช่ข้อมูลผลผลิตจริงของไซต์นี้
  โดยเฉพาะ (ยังไม่มีข้อมูลนั้น)
- ฝนพยากรณ์ผิดได้ — มีระบบยืนยัน/แก้ไขอัตโนมัติทุกเช้าผ่าน TMD แต่ยังมี delay ~1 วัน
- รายละเอียดเต็มดูในแท็บ **"เกี่ยวกับโมเดล"** ของแดชบอร์ด (มีตารางเทียบงานวิจัย, แหล่งอ้างอิง,
  และผลการตรวจสอบทุกจุด)
